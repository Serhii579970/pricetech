# PriceTech

PriceTech — сайт, де користувач бачить актуальні ціни Сільпо та АТБ у єдиному каталозі, може шукати й фільтрувати товари. Ціни оновлюються щодоби, тож видно, як вони змінюються.

## Запуск

```bash
python3 server.py
```

Потім відкрийте http://localhost:8000

Налаштування: `PORT` (за замовчуванням 8000), `UPDATE_HOURS` (за замовчуванням 24).

## Структура проєкту

- `index.html` — головна сторінка (лендинг). Використовує `style.css`, `app.js` та `assets/logo.png`.
- `search.html`, `search.css`, `search.js` — каталог товарів (кнопка «Почати зараз» веде сюди).
- `server.py` — сервер з щодобовим оновленням цін.
- `update_once.py` — разове оновлення даних (для планувальника на хостингу).
- `wsgi_app.py` — запуск через WSGI (PythonAnywhere).
- `pages/` — збережені сторінки категорій atbmarket.com.
- `pages_silpo/` — збережені сторінки категорій silpo.ua.
- `atb_export.csv` — запасне джерело даних АТБ.
- `data/` — товари й ціни (`products.json`) та добові копії.

## Збереження даних між оновленнями

- Усі товари й ціни лежать у `data/products.json` (плюс добові копії в `data/backup/`, останні 14). Шлях можна змінити через `DATA_DIR`.
- Під час оновлення сайту папку `data/` не видаляйте. Після перезапуску сервер підхопить старі дані й одразу оновить їх.
- Якщо джерело тимчасово недоступне (API Сільпо, АТБ), його попередні товари переносяться в нове оновлення, а не зникають.

## Джерела даних

### Сільпо (автоматично)

Сервер щодоби (кожні `UPDATE_HOURS`) звертається до JSON API silpo.ua і додає товари з назвою, ціною, старою ціною, фото та посиланням.

- `SILPO_CATEGORIES` — slug-и категорій через кому (з адреси `silpo.ua/category/<slug>`); `slug=Підпис` задає мітку на картці для товарів без знижки.
- `SILPO_ENABLED=0` — вимкнути Сільпо.
- `SILPO_BRANCH` — id філії (за замовчуванням «усі»; ціни можуть відрізнятися по філіях).
- Якщо API недоступне, лишаються попередні товари Сільпо з `data/products.json`.
- Якщо сайт змінить формат запиту, скопіюйте query-рядок запиту `/products` з DevTools → Network у `SILPO_QUERY` (плейсхолдери `{limit}`, `{offset}`, `{slug}`).

Приклад:

```bash
SILPO_CATEGORIES="15-povertayemo-balobonusamy=15% балобонусами,pyvo-100" python3 server.py
```

### Збережені сторінки

- `pages_silpo/` — сторінки категорій silpo.ua (Ctrl+S → «Лише HTML»; `.html`, `.htm`, `.txt`). Нові сторінки (`?page=2` тощо) просто кладіть у цю папку.
- `pages/` — сторінки категорій atbmarket.com (Ctrl+S → «Веб-сторінка, лише HTML»). Скрипт сам читає картки товарів, відкидає дублікати й оновлює `products.json`.

### АТБ: фід і CSV

Пріоритет джерел: фід → папка `pages/` → CSV.

- `ATB_FEED_URL=https://.../feed.json python3 server.py` — офіційний або партнерський фід (JSON чи CSV). Назви полів можна підігнати у словнику `ALIASES` у `server.py`.
- Без змінної береться файл `atb_export.csv` (колонки: `name`, `brand`, `category`, `price`, `old`, `store`).

Якщо оновлення не вдалося, лишаються попередні дані. Якщо API недоступне, сайт показує вбудовані демо-товари.

## Хостинг на PythonAnywhere

1. Files → завантажте zip, у Bash-консолі: `unzip pricetech-server-silpo.zip`.
2. `cd ~/pricetech-server && python3 update_once.py` — створить `data/products.json`.
3. Web → Add a new web app → Manual configuration → Python 3.10+. У WSGI configuration file вставте:

   ```python
   import sys
   sys.path.insert(0, "/home/ВАШ_ЛОГІН/pricetech-server")
   from wsgi_app import application
   ```

4. Web → Reload. Сайт: `https://ВАШ_ЛОГІН.pythonanywhere.com`.
5. Tasks → Scheduled → щодня: `python3 /home/ВАШ_ЛОГІН/pricetech-server/update_once.py`.

Безкоштовний акаунт: раз на ~3 місяці натискайте на вкладці Web кнопку «Run until 3 months from today», інакше сайт вимкнеться. Вихід в інтернет обмежений списком дозволених сайтів — перевірте командою `curl -sI https://sf-ecom-api.silpo.ua | head -1`. Якщо не відповідає, Сільпо оновлюватиметься лише зі збережених сторінок `pages_silpo/`.

## Як ми працюємо з Git

- Напряму в `main` ніхто не пише. Кожна зміна: гілка → pull request → рев'ю одногрупника → злиття.
- Кожен PR прив'язаний до задачі: в описі `Closes #номер` (issue в GitHub) або номер задачі з Jira.
- Кожен комітить зі свого акаунта. Працювали в парі — додайте в кінець коміту рядок `Co-authored-by: Ім'я <пошта>`.
- Спринти ведемо в Jira, помилки — в GitHub Issues.
