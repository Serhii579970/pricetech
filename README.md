
# PriceTech + щодобове оновлення цін

Запуск: `python3 server.py`, потім відкрийте http://localhost:8000

## Збереження даних між оновленнями
- Усі товари й ціни лежать у `data/products.json` (+ добові копії в `data/backup/`, останні 14). Шлях можна змінити через `DATA_DIR`.
- **Оновлення сайту:** розпакуйте нову версію поверх старої (або замініть файли), папку `data/` не видаляйте — архів її не перезаписує. Після перезапуску сервер підхопить старі дані й одразу оновить їх.
- Якщо джерело тимчасово недоступне (API Сільпо, АТБ), його попередні товари переносяться в нове оновлення, а не зникають.
- Старий `products.json` поруч із `server.py` автоматично переноситься в `data/` при першому запуску.
- Папка `pages_silpo/` — збережені сторінки категорій silpo.ua (Ctrl+S → «Лише HTML», .html/.htm/.txt). Товари з них додаються при кожному оновленні й їдуть у архіві разом із кодом (зараз там «Сезонні овочі, фрукти», «Фрукти» і «Ягоди» — по 47 товарів зі сторінки 1; решту сторінок додавайте так само). Нові сторінки (?page=2…) просто кладіть у цю папку.

## Сільпо — автоматично
Сервер сам щодоби (кожні `UPDATE_HOURS`) звертається до JSON API silpo.ua і додає товари до сайту з назвою, ціною, старою ціною, фото та посиланням на товар. Нічого зберігати вручну не треба.
- `SILPO_CATEGORIES` — slug-и категорій через кому (з адреси `silpo.ua/category/<slug>`); `slug=Підпис` задає мітку на картці для товарів без знижки. За замовчуванням: основні відділи (молочні, овочі й фрукти, ковбаси, бакалія, напої, солодощі, морозиво, заморожені продукти, алкоголь).
- `SILPO_TOP` — скільки найпопулярніших товарів брати з кожної категорії (30). `0` — усі.
- `SILPO_ENABLED=0` — вимкнути Сільпо. `SILPO_BRANCH` — id філії (за замовчуванням «усі»; ціни можуть відрізнятися по філіях).
- Якщо API недоступне — лишаються попередні товари Сільпо з `data/products.json`.
- Якщо сайт змінить формат запиту, скопіюйте query-рядок запиту `/products` з DevTools → Network у `SILPO_QUERY` (плейсхолдери `{limit}`, `{offset}`, `{slug}`).
Приклад: `SILPO_CATEGORIES="15-povertayemo-balobonusamy=15% балобонусами,pyvo-100" python3 server.py`

## Ашан — автоматично
Сервер при кожному оновленні (кожні `UPDATE_HOURS`) бере товари з онлайн-каталогу Ашан на zakaz.ua (`stores-api.zakaz.ua`): назва, ціна, стара ціна (якщо є знижка), фото та посилання на товар. Ціни оновлюються разом зі зміною на сайті, нічого зберігати вручну не треба.
- `AUCHAN_STORE_ID` — id магазину Ашан на zakaz.ua (ціни залежать від магазину). За замовчуванням `48246409` (Ашан Львів).
- `AUCHAN_CATEGORIES` — slug-и категорій через кому (з адреси `auchan.zakaz.ua/uk/categories/<slug>/`); `slug=Назва` задає назву відділу на сайті. За замовчуванням: молочні й яйця, овочі й фрукти, м'ясо/риба, хліб, бакалія, солодощі, консерви, соуси, напої, чай/кава, заморожені, готові страви, алкоголь.
- `AUCHAN_TOP` — скільки перших товарів брати з кожної категорії (30, у порядку видачі каталогу). `0` — усі.
- `AUCHAN_ENABLED=0` — вимкнути Ашан.
- Якщо API недоступне, лишаються попередні товари Ашан з `data/products.json`.
- Тести без мережі: `python3 -m unittest discover -s tests -v`.

## Інші джерела (за пріоритетом: фід → папка pages/ → CSV), додаються до Сільпо:
- Папка `pages/` — збережені сторінки категорій atbmarket.com (Ctrl+S → «Веб-сторінка, лише HTML»; .html/.htm/.txt). Скрипт сам читає картки товарів (назва, ціна, фото та посилання на товар), відкидає дублікати між файлами й оновлює `products.json`. Щоб додати категорії чи наступні сторінки (?page=2, 3...), просто покладіть нові файли в `pages/` і перезапустіть скрипт.
- `ATB_FEED_URL=https://.../feed.json python3 server.py` — офіційний/партнерський фід (JSON або CSV).
  Назви полів можна підігнати у словнику `ALIASES` у server.py.
- Без змінної береться файл `atb_export.csv` (колонки: name, brand, category, price, old, store).

Налаштування: `PORT` (8000), `UPDATE_HOURS` (24).
Якщо оновлення не вдалось, лишаються попередні дані (products.json). Якщо API недоступне, сайт показує вбудовані демо-товари.
Для постійної роботи запускайте через systemd або Docker на своєму сервері.

## Хостинг на PythonAnywhere
1. Files → завантажте zip, у Bash-консолі: `unzip pricetech-server-silpo.zip` (папка `~/pricetech-server`).
2. Bash-консоль: `cd ~/pricetech-server && python3 update_once.py` — створить `data/products.json`.
3. Web → Add a new web app → Manual configuration → Python 3.10+. У розділі WSGI configuration file замініть вміст на:
   ```
   import sys
   sys.path.insert(0, "/home/ВАШ_ЛОГІН/pricetech-server")
   from wsgi_app import application
   ```
4. Web → Reload. Сайт: `https://ВАШ_ЛОГІН.pythonanywhere.com`.
5. Tasks → Scheduled → щодня: `python3 /home/ВАШ_ЛОГІН/pricetech-server/update_once.py`.
6. Безкоштовний акаунт: раз на ~3 місяці натискайте на вкладці Web кнопку «Run until 3 months from today», інакше сайт вимкнеться. Вихід в інтернет там обмежений списком дозволених сайтів — перевірте командою `curl -sI https://sf-ecom-api.silpo.ua | head -1`; якщо не відповідає, Сільпо оновлюватиметься лише зі збережених сторінок `pages_silpo/`.

## Структура сайту
- `index.html` — головна (лендинг). Їй потрібні **ваші** `style.css`, `app.js` та `assets/logo.png` (+ картинка hero з CSS) — покладіть їх поруч.
- `search.html` + `search.css` + `search.js` — каталог товарів (кнопка «Почати зараз» веде сюди). Логотип у меню повертає на головну.
- З `assets/` сервер віддає лише картинки.
